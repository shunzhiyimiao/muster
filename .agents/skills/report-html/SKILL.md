# 自包含 HTML 报告规范

## 文件
- 只有一个文件 report.html,不引用外部 CSS / JS / 字体 / 图片;样式全写在 `<style>`,图表全用内联 `<svg>`。
- `<html lang="zh-CN">`,`<meta charset="utf-8">`,`<title>` 里带日期。
- 打印友好:内容宽度不超过 800px,不用固定定位,不用深色背景整页;PDF 由系统用 Chrome 打印,你不用管。

## 结构(按顺序)
1. 标题、日期、一句话结论。
2. 关键指标卡片 3 到 6 个:名称、最新值、日涨跌。涨跌用 ▲ / ▼ 符号加颜色,颜色含义在页脚说明一次。
3. 对比表格:列为 指标 / 最新 / 前值 / 变化 / 变化%;取不到的写"缺失",不要留空、不要编数。
4. 图表(见下)。
5. 数据来源与抓取时间;缺失项的说明。

## 内联 SVG 画法
- 横向柱状图:`viewBox="0 0 640 H"`,H = 行数 × 28 + 20;每行一个 `<rect>`,零轴在 x=320,正值向右、负值向左,长度按最大绝对值归一化到 280;数值用 `<text>` 标在条的外侧,标签放在零轴左侧 8px。
- 小折线:`viewBox="0 0 200 60"`,x 按 i/(n-1)×200,y 按 (max-v)/(max-min)×50+5;`<polyline fill="none" stroke-width="2">`,末点画一个半径 2.5 的圆。
- 颜色只用三种:主色 #5B5BF5、上涨 #C0392B、下跌 #1E8449;文字 12 到 14px,灰字 #6B7280。

## 数字与文风
- 数值两位小数,百分比带 %,千位分隔。
- 结论直接给,不写"根据我的分析"之类的话;不确定的地方写"数据缺失"或"仅供参考",不要含糊带过。
