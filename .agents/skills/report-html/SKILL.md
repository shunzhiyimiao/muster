# 自包含 HTML 报告规范

## 文件
- 只有一个文件 report.html,不引用外部 CSS / JS / 字体 / 图片;样式全写在 `<style>`,图表全用内联 `<svg>`。
- `<html lang="zh-CN">`,`<meta charset="utf-8">`,`<title>` 里带日期。
- 打印友好:内容宽度不超过 800px,不用固定定位,不用深色背景整页;PDF 由系统用 Chrome 打印,你不用管。

## 结构(按顺序)
1. 标题、日期、一句话结论。
2. 关键指标卡片 3 到 6 个:名称、最新值、日涨跌。涨跌用 ▲ / ▼ 符号加颜色,颜色含义在页脚说明一次。
3. 对比表格:列为 指标 / 最新 / 前值 / 变化 / 变化%;取不到的写"缺失",不要留空、不要编数。
4. 图表(见下)。
5. 数据来源与抓取时间;缺失项的说明。

## 内联 SVG 画法

### 横向柱状图:三列固定布局,标签不许挪
名称列、柱子区、数值列各占固定位置,**不论数值大小、正负,标签位置都不变**——把标签贴在柱子端点会在小值时互相压住,这是实测踩过的坑。

- `viewBox="0 0 660 H"`,H = 行数 × 28 + 20;第 i 行(从 0 起)的柱子 y = 10 + i×28,高 16,文字基线 y + 12。
- 名称:`<text x="150" text-anchor="end">`,永远在这一列。
- 零轴:`<line x1="390" y1="6" x2="390" y2="H-6" stroke="#D1D5DB"/>`。
- 柱长 L = |值| ÷ max|值| × 190;正值 `x="390"`,负值 `x="390-L"`;L 不足 1 就画 1(零值也要有一根细线)。
- 数值:`<text x="652" text-anchor="end">`,永远在这一列,带正负号与百分号,颜色同柱子。
- 一行的完整写法(其余行只改 y 与数值):

```svg
<text x="150" y="22" font-size="12" fill="#374151" text-anchor="end">日经 225</text>
<rect x="390" y="10" width="190" height="16" fill="#C0392B"/>
<text x="652" y="22" font-size="12" fill="#C0392B" text-anchor="end">+1.38%</text>
```

负值一行:柱子从 390 向左延伸,数值仍在右列。

```svg
<text x="150" y="50" font-size="12" fill="#374151" text-anchor="end">恒生指数</text>
<rect x="250" y="38" width="140" height="16" fill="#1E8449"/>
<text x="652" y="50" font-size="12" fill="#1E8449" text-anchor="end">-1.01%</text>
```

### 小折线
- `viewBox="0 0 200 60"`,x 按 i/(n-1)×200,y 按 (max-v)/(max-min)×50+5(max = min 时全画在 y=30);
- `<polyline fill="none" stroke="#5B5BF5" stroke-width="2">`,末点画一个半径 2.5 的圆;
- 一张卡片一条线,标题里写清楚是哪个指数、缺了哪天。

### 颜色与字号
- 只用三种颜色:主色 #5B5BF5、上涨 #C0392B、下跌 #1E8449;文字 12 到 14px,灰字 #6B7280。
- 颜色含义在页脚说明一次(红涨绿跌是中文市场习惯)。

## 数字与文风
- 数值两位小数,百分比带 %,千位分隔。
- 结论直接给,不写"根据我的分析"之类的话;不确定的地方写"数据缺失"或"仅供参考",不要含糊带过。
