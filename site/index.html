[ 02 ] 保证

不是承诺。 是代码。

三条保证，各自对应一个写不出违反它的数据结构。

[ A ]

密级只升不降。

接触过更敏感的材料，整段会话就按那个级别对待。会话棘轮里，压根没有"降低"这个接口。

[ B ]

绝不悄悄上云。

本地模型不可用时，任务不会顶到云端。它会被明确拒绝，并留下一条记录。

[ C ]

每个数字都能查。

谁调了哪个模型、外发了多少字节、谁批准了什么——都是一条 SQL 从审计链里查出来的。

[ 03 ] 密级路由

你的数据， 留在你的网络里。

模型用哪个，不由谁随手一选。每个频道、每个仓库、每场会议都带着密级，系统取其中最高的那个，只把任务派给允许的通道。

公开public 内部internal 敏感confidential 受限restricted
本地 · Ollama qwen3:8b ✓ 可落
云端 · Kimi K3 ✗ 已排除

箭头只有一个方向。受限级的任务只落本地，受限级的会议不许录制。

[ 1 ]

打标签

频道、仓库、手动标记、会话锁，各自有一个密级。

[ 2 ]

取最高

有效密级取四者之中的最大值，在会话里只升不降。

[ 3 ]

只落允许的通道

落不下，就拒绝。降落带只接受本地模型，"本地挂了改走云端"这条路根本不存在。

[ 04 ] 编制

八个格子， 就是整个平台。

图标里的每一格，都是平台上的一块。Agent 和人一样在编制里：有岗位、有权限上限，被 @、被派活、被审批。

会议室

开会时，它在听。

实时纪要，按各人所选语言的字幕，散会回顾，录制回放。转写只走本地模型。

每个任务，一个独立工作区。

主仓零污染，产出就是一份 diff。出网默认全拒，每次连接都记一笔。

[ 06 ] 部署

哪种部署适合你？

三种形态，同一套代码。运行时都不依赖公网。

个人本地版

一台电脑，装好就能用。

SQLite 本机 Runner 本地模型 个人开发者 · 技术验证

企业内网版

一个团队，一套服务，
Docker Compose 一次拉起。

PostgreSQL 集中或各人机器上的 Runner 内网模型服务 研发团队 · 金融 · 制造 · 医疗

隔离网版

与公网物理隔离，
依赖全部预先带入。

PostgreSQL 集中 Runner 预置本地模型与转写 受监管行业 · 内网隔离单位
有自己的域名？一条命令上线。 预检 DNS 与端口，安装 Docker，拉起全套服务，自动签发 HTTPS 证书，创建第一个管理员。 $ ./deploy/to-server.sh ubuntu@<IP> your.domain
