1. 决策摘要与范围
本项目不是简单地为 Codex 增加聊天室，而是构建一个可完全本地部署的 AI 原生团队开发协作系统。它将人员、群组、频道、消息、工作流、Codex Agent、Git Worktree、审批和审计组织为统一的执行平台。
已确定的架构决策 Fork Codex，但保持协作系统与 Codex Fork 分仓；Rust 是核心语言；客户端采用 Tauri 2，前端允许 React + TypeScript；服务器、Runner、模型与数据可全部部署在企业内网；工作流是可版本化、可审批、可验证的软件对象。

3.1 技术边界原则
• Rust 核心是业务真相来源；UI 不复制权限、预算、任务状态机和审批规则。
• Codex Fork 只包含 Agent Runtime、本地 Provider、离线模式、安全 Hook 和必要协议扩展；Group/Channel/Chat 不写进 Codex Core。
• PostgreSQL 是服务器共享事实来源；Tokio broadcast、NATS 和 WebSocket 都只是事件传输机制。
• 所有外部工具必须通过声明能力、权限策略和审计日志接入。
• 先调用系统 Git CLI；只有明确遇到性能或可移植性瓶颈时再引入 git2。

5.2 消息写入与广播顺序
客户端发送 message.create   ↓ 服务器校验 Token、Channel Membership 与权限   ↓ 开启 PostgreSQL 事务   ↓ 写入 message + channel_sequence + outbox_event   ↓ 提交事务   ↓ Outbox Dispatcher 广播到 WebSocket / NATS   ↓ 其他客户端确认 event_id   ↓ 断线时通过 after_event_id 补拉
必须采用 Transactional Outbox 先入库、再广播仍可能在两者之间崩溃。第一版也建议在同一事务写入 outbox_events，由后台 Dispatcher 可靠发布；客户端使用 event_id 幂等处理。

5.5 WebSocket 会话规则
• 连接建立后立即完成身份认证，并返回 connection_id、server_time 和 heartbeat_interval。
• 客户端订阅 Organization / Channel / Task topic；服务端再次检查权限，不能信任客户端提交的范围。
• 所有可重放事件都有 event_id；客户端按 event_id 去重。
• 断线重连提交 last_event_id；若保留窗口已过，则调用 REST 进行全量同步。
• 心跳只表示连接存活，不等于用户在线；Presence 采用多设备会话聚合。
• 对 Agent 流式内容实施背压、批量合并和速率限制，避免每个 Token 一次数据库写入。

7.3 第一版调度规则
• 1. Runner 在线且心跳有效
• 2. 有空闲并发槽位
• 3. 允许访问目标仓库
• 4. 操作系统和架构满足工作流要求
• 5. workspace root 与构建环境可用
• 6. 模型 Provider 与工具能力满足要求
• 7. 安全策略和网络策略允许
• 8. 在候选中按最少负载 + FIFO 选择
7.4 Worktree 规则
• 一个 Task Run 对应一个独立 Worktree；禁止多个并行任务共享同一可写目录。
• 分支名称包含 task_id，但对用户展示可读别名。
• 执行前检测基础仓库是否存在未提交改动、分支是否可用。
• 所有 Shell 命令的 cwd 被约束到 Worktree 或声明的 workspace roots。
• 任务结束后先保存 Diff、日志、证据与 Commit，再依据保留策略清理。
• 自动 Push 和 PR 创建必须单独授权，不属于默认完成动作。

15. 验收标准与 Definition of Done
15.1 功能 DoD
☐ 代码包含单元测试或集成测试，CI 通过 fmt、clippy 和 test。
☐ 权限校验在服务器或 Runner 的可信边界执行，不能仅依赖 UI。
☐ 所有状态转换经过状态机，非法转换有测试。
☐ 对外 API 和事件 Schema 有版本和示例。
☐ 失败路径、取消、超时、重试和幂等行为已验证。
☐ 关键动作产生结构化 tracing 和 audit event。
☐ 文档包含配置、启动、回滚和常见故障。
15.2 安全 DoD
☐ 运行时无未授权公网请求。
☐ Secret 不进入日志、消息、Diff 或审计正文。
☐ Runner 使用服务账号，不复用个人 Token。
☐ 文件和命令越界操作被拒绝或进入审批。
☐ 审计记录不可由普通用户更新或删除。
☐ 依赖、镜像和安装包有版本锁定与许可证记录。
