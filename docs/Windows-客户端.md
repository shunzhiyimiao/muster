# Windows 客户端

## 先分清:你需要的是哪一个

参会**不需要装任何东西**。浏览器打开 `http://<服务器>:8787/web` 就能登录、进会、
开麦、看实时纪要、发消息。你已经这么用过了。

桌面壳解决的是浏览器做不到的那部分:**在自己机器上跑任务**——本地 Runner、
本地审计链、本地正文库、审批合入。这些要访问本机文件系统和 git,
浏览器里做不了,**也不该假装能做**。

| 你要做的事 | 用什么 |
|---|---|
| 开会、说话、看纪要、发消息 | Chrome 打开 `/web`,什么都不用装 |
| 跑任务、审批 diff、看本地审计链 | 桌面壳 |
| 只是想试试 | 先用网页端 |

## 拿安装包

安装包由 CI 在 Windows 机器上构建,**不是从 Mac 交叉编译出来的**——
交叉编译能不能成全看运气,而"装上能不能跑"在 Mac 上根本验不了。

```bash
gh run list --workflow=desktop-windows.yml --limit 3     # 找一次成功的构建
gh run download <run-id> -n muster-desktop-windows       # 下载
```

或在 GitHub 网页上进 Actions → 桌面壳 · Windows → 选一次成功的运行 → Artifacts。

产物是 `muster-desktop_<版本>_x64-setup.exe`,**约 207MB**。

## 装

双击即可,**不需要管理员权限**——装在当前用户下。内网办公机通常不给普通用户
提权,装个内部工具还要找 IT 的话,这工具就没人用。

### 为什么安装包有 207MB

大头是打进去的 WebView2 离线运行时。Windows 11 自带 WebView2,Windows 10 多数
也有,但**内网机器装不了要联网的引导器**——真缺的时候,安装会以一个网络错误
失败,而这个系统的整个前提就是不依赖公网。

宁可让包大,也不要让"装不上"这件事取决于有没有外网。

要换小的:把 `tauri.conf.json` 里 `windows.webviewInstallMode` 改成
`downloadBootstrapper`(约 2MB,装的时候现下)或 `skip`(假定机器上已有)。
确认目标机器都有 WebView2 的话,`skip` 最省。

## 连服务器

启动后填服务器地址(`http://<服务器 IP>:8787`)、账号、口令。

服务器和 Windows 机器必须在**同一个局域网**,而且服务器要监听对外地址而非
`127.0.0.1`——这一条在 `docs/多人会议测试计划.md` 里有完整的排查步骤。

**不填服务器也能用**,那是单机模式:本地跑任务、本地审计链,一切与联网前一致。
单机才是这个产品的入口形态,加了联网模式不该让它退化。

## 这台机器上还需要装什么

桌面壳自己不需要 Rust 或 Node,但**它跑的任务需要**。Runner 在隔离 worktree 里
执行命令,命令用的是这台机器上的工具链:

| 要做的事 | 需要 |
|---|---|
| 跑任何任务 | **git**(worktree 隔离靠它,没有就一步都走不了) |
| 任务里跑 `cargo test` / `cargo build` | Rust 工具链 |
| 任务里跑 `npm test` / `pnpm test` | Node |

只想开会和看纪要的话,这些一个都不用装。

> `npm` / `pnpm` / `yarn` 在 Windows 上是 `.cmd` 批处理,而 Rust 的
> `Command::new("npm")` 只补 `.exe` 不查 `PATHEXT`。Runner 里已经自己做了
> `PATH × PATHEXT` 解析,**但只查 PATH、绝不查当前工作目录**——
> cwd 是模型刚写完文件的隔离 worktree,从那里取可执行文件等于让被测代码
> 自己决定 `npm` 是什么。

## 已知的平台差异

**会话文件的权限。** Unix 上令牌文件会 `chmod 600`;Windows 上依赖家目录本身的
ACL,没有额外收紧。同一台机器上有其他用户账户时,这是一个差别。

**审计链是每节点各自一条。** 你的 Windows 机器和 Mac 各留各的链,服务端不做
全局链。组织级的防篡改要靠锚定,**那个还没做**——现在服务端存的东西被改了,
没有机制能发现。这是记在 `muster-server/src/lib.rs` 诚实边界里的已知欠账。

## 出了问题

装完打不开,先确认是 WebView2 还是别的:任务管理器里看进程起没起。
起了但白屏通常是 WebView2;根本没起是安装本身的问题。

连不上服务器,按 `docs/多人会议测试计划.md` 的排查顺序走——那份文档是双人
实测时逐条踩出来的,顺序有意义:先验服务器监听地址,再验防火墙,最后才怀疑客户端。
